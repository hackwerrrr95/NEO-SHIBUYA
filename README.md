# 🌙 Tokyo Night — Vencord Theme

A dark Japanese-inspired Discord theme for **Vencord**, combining a Tokyo Night atmosphere with neon accents and a sleek modern interface.

## ✨ Features

* 🌃 Dark Tokyo Night aesthetic
* 🇯🇵 Japanese-inspired design
* 💜 Neon accents
* 🖥️ Custom Discord interface
* ⚡ Lightweight and optimized
* 🎨 Designed specifically for Vencord

## 📥 Installation

### Vencord

1. Open **Discord**
2. Go to **User Settings**
3. Open **Vencord → Themes**
4. Under **Online Themes**, add the following URL:

```text
https://raw.githubusercontent.com/YOUR-USERNAME/YOUR-REPOSITORY/main/TokyoNight.css
```

5. Enable the theme.
6. Enjoy 🌙

### 🛠️ Manual Installation

You can also download `TokyoNight.css` from this repository and add it manually to your Vencord themes folder.

## 🎨 Customization

You can edit the CSS variables at the top of the file to customize colors, transparency, backgrounds, and accents.
